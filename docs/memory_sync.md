# 跨端记忆同步

中期和长期记忆通过自建 HTTPS 服务在同一用户的设备间合并。短期对话上下文、会话轨迹、主动任务、MCP/OAuth 凭据和模型文件不参与同步。服务端保存记忆正文，因此部署者必须保护数据库和备份；TLS 只保护传输。

## 启动服务

准备受设备信任的 TLS 证书和私钥，为每个用户生成高熵随机令牌。`MEMORY_SYNC_TOKENS` 是“令牌 → 用户 ID”的 JSON 映射，例如 `{"<随机令牌>":"user-1"}`。将其放在受限权限的进程环境文件中，不要提交到仓库或写入命令行参数。启动服务时通过进程管理器注入环境变量：

```sh
python3 scripts/memory_sync_server.py \
  --db /secure/path/memory-sync.sqlite \
  --cert /secure/path/fullchain.pem --key /secure/path/privkey.pem \
  --host 0.0.0.0 --port 9443
```

服务接口为 `https://主机:9443/v1/memories/sync`。每台设备在设置中填入同一地址和令牌，保存后立即同步；App 运行时每 15 分钟同步，并在对话后尝试同步。网络失败保留本地修改，下次重试。清空地址可停用该设备的同步。

服务按令牌映射的用户 ID 隔离记录，按记忆 ID、修订时间和设备 ID 合并；删除记录以墓碑传播，避免其他设备在下一轮同步时恢复。端侧在同步前扫描本地记忆表的变化，因此端侧模型和用户修改都可被同步。当前为完整快照交换，单次最多 10,000 条、请求和响应最多 4 MiB。设备时钟应保持同步；同一记忆的并发修改使用修订时间和设备 ID 确定性决胜，暂不提供冲突审阅。令牌轮换、分页、端到端加密和设备撤销仍需部署与产品层扩展。

Android 令牌存入 Keystore 加密偏好，iOS 存入 Keychain。桌面 JVM 当前存入系统 Preferences；部署在共用账号的 Mac 上前，应改接系统 Keychain。
