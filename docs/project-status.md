## 暂不实施

用户本轮明确暂不实施远程 APNs 和正式发行。手机退出后的实时模型推理、远程结果推送及持续自动接单不能承诺；恢复前台后继续拉取。Mac 接单使用独立 worker，不能和 UI 同时占用同一数据目录。
